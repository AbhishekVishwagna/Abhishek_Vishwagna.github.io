# Abhishek Basavaraj Vishwagna | Portfolio

Personal portfolio of an embedded systems engineer. The site is styled like a PCB and includes a working oscilloscope, expandable project cards, a skills "datasheet" and a small terminal.

**Live site:** https://abhishekvishwagna.github.io/Abhishek_Vishwagna.github.io/

## About me

I have about 1.5 years of startup experience in embedded systems and a published paper in Human-Computer Interaction. I work with STM32, ESP32 and Raspberry Pi, and I'm looking for embedded systems, firmware and electronics roles in the UK and Europe.

## Features

- **Projects:** expandable cards with the stack and details for each project.
- **Skills:** filter by group and select a pin to read its entry.
- **Terminal:** type `help`, `about`, `skills`, `projects` or `contact`.
- **Responsive and accessible:** works on phones, supports keyboard navigation, and respects reduced-motion settings.

## Built with

HTML, CSS and plain JavaScript in a single file. There are no frameworks, no build step and no dependencies. Fonts (Barlow, Barlow Condensed, IBM Plex Mono) load from Google Fonts, and the page falls back to system fonts without them.
